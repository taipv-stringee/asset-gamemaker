# asset-gamemaker

Kho chứa nhiều game làm bằng GameMaker LTS 2026, mỗi game một thư mục riêng.

| Thư mục | Nội dung |
|---|---|
| `games/` | Game đang làm thật (mỗi game: project GameMaker + asset + README). |
| `drafts/ca-chep-vu-mon/` | **Nháp** — Cá chép vượt Vũ Môn: asset pixel art sinh bằng Python và project `CaChepVuMon/`. |
| `references/material_8/` | Project mẫu `material_8` (khóa GI, MindX) — top-down: người chơi 4 hướng, vũ khí, đạn, rương, kẻ địch đuổi/tấn công, cổng dịch chuyển qua 3 room. Dùng làm nền logic cho game mới. |

Mở một project: chọn file `.yyp` trong thư mục tương ứng bằng GameMaker.
